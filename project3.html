Project 3 · Kyle Wang · EECS 367

Forward kinematics

Disco Point

Robot

A custom URDF arm with a rotating base, shoulder, and elbow. A vertical sliding joint adds a small bounce, and a fixed finger makes the pointing direction clear.

Choreography

A custom FSM alternates high and low points four times, performs two fist pumps, holds a high pose, and returns to Ready. Joints move smoothly between targets, with brief holds during the pointing sequence.

Rendering

Recorded using make demo with this robot and choreography loaded. A separate three.js viewer receives /xform_world from the C++ runtime through a Python TCP/JSON bridge. It draws each link using its column-major world matrix and URDF visual offset.
