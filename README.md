# AutoRob course portfolio

Kyle Wang's EECS 367 portfolio, published with GitHub Pages.

The site contains static HTML, CSS, and the silent Project 3 video. The coursework runtime is maintained separately.

GitHub Pages serves the root of the `main` branch. Edit these files and push to `main` to update the site.

Preview locally with `python3 -m http.server 8783` and open `http://localhost:8783/`.
